SPECIFICATION & ARCHITECTURE FRAMEWORK

Judarn Document Design Specification

Judarn Design Foundation • Typography Specification

1. Scope and Typographic System

This specification establishes the official typographic, spatial, and color foundation for all Judarn long-form documents. It covers the page's type, spacing, and color.

Body text is set in black (#000000) for long-form reading.

Intra-paragraph line spacing is held strictly to single leading (1.0 in word processors, 1.25 in rendering engines), which keeps a paragraph together as one block. Paragraphs are separated by an 8 pt trailing margin instead of empty lines.

1.1 Alternating Typeface Hierarchy

To tell heading levels apart at a glance, this template alternates typefaces: the Title is set in IBM Plex Serif, Heading 1 steps into IBM Plex Sans, and Heading 2 returns to IBM Plex Serif.

1.1.1 Sub-Topics

Sub-topics step down to 13 pt IBM Plex Sans Semi-Bold. That is 18% larger than the 11 pt body text, in a heavier weight, so sub-sections stand apart from body prose.

1.1.1.1 Run-In Subsection & Micro Hierarchy

When micro subsections require demarcation, Heading 4 matches the 11 pt body baseline in full Bold (700) weight. It marks the boundary without adding height.

1.2 Tabular Numbers & Monospace Invariants

For code snippets, technical hashes, and numeric data matrices, IBM Plex Mono provides equal-width tabular lining figures. Because IBM Plex Sans and Mono share identical vertical metrics (516 x-height, 698 cap height), inline code like JudarnColors.substrate sits on the 11 pt body baseline without changing the line height. Standalone code blocks are calibrated to 9.5 pt with single line leading to balance the wider horizontal advance of monospace glyphs and maximize column capacity:

const judarnTokens = {
  body: "11pt",
  heading1: "20pt",
  heading2: "16pt",
  heading3: "13pt",
  codeBlock: "9.5pt",
  spaceAfter: "8pt"
};

Core Architecture Principle: Color is strictly removed from body paragraphs and restricted to structural anchors: callout indicator rules, table header boundaries, and metadata status badges using Sanzo Wada Combination 119.
