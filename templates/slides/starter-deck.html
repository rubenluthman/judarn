EXECUTIVE BRIEFING

Cross-Platform Spatial Rhythm & Surface Contrasts

Surfaces are grouped by fill, not by outline

Why not borders

Borders drawn around every card compete with the content inside them. Grouping by fill keeps the eye on the data instead of the container.

Fill instead of outline

Judarn groups surfaces by background fill. Elevated cards (#F8F8F8) sit on a white (#FFFFFF) substrate with no perimeter border; the step in fill separates them.

Core Invariant: Distinguish surfaces by background fill contrast (surfaceElevated on substrate). Never apply .border() or .overlay(strokeBorder()) around card perimeters. Hairlines belong only inside tabular matrices.

FOUNDATIONAL ARCHITECTURE

The Three Judarn Platform Invariants

A clean authority split between design tokens and native operating system mechanics

01
OKLCh Color & Grid
Colors are authored in OKLCh for light and dark appearances. Spacing snaps to an 8 pt grid with a 4 pt subgrid.
02
Native Curve Authority
Judarn never overrides host platform physics, hardware curves, or native interaction states. Squircle geometry and corner radii belong to the operating system.
03
Sanzo Wada Harmony
Optional accents from Sanzo Wada's color combinations (Tyrian Blue and Olympic Blue), used here for indicators, data tables, and badges.

SPECIFICATION

Token Interface

Shared contract between compile-time token sources and runtime renderers

Token Pipeline

Design tokens originate in tokens/judarn-tokens.json which follows the Design Tokens Format Module 2025.10. A build script compiles them into Swift constants and CSS custom properties, and a check fails when the output drifts from the source.

// Judarn token excerpt const judarnContract = { grid: { macro: 8, micro: 4 }, colors: { substrate: "oklch(1.000 0.000 0)", elevated: "oklch(0.980 0.000 0)", tyrian: "#12354e", glaucous: "#a5c8d1" }, authority: { judarn: ["color", "type", "grid"], native: ["curves", "motion", "touch"] } };

TRADE-OFFS

Conventional Libraries and Judarn

What changes when the host owns geometry and touch

Conventional UI Libraries
– Overrides native controls, so touch behavior differs from the host
– Applies decorative stroke borders around every card perimeter
– Uses one-off spacing values that break the rhythm
– Ties styling to large components that change often
Judarn Design Foundation
✓ Leaves platform physics, curves, and haptics to the host
✓ Groups surfaces by background fill, no perimeter borders
✓ 8 pt grid with a 4 pt subgrid
✓ Every host compiled from one token source
