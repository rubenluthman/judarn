LogoLockup frames a geometric mark and a heavy sans wordmark, in four variants: `horizontal` (the default), `vertical`, `icon` and `reversed`.

Use `reversed` on a dark fill and `icon` where only the mark fits. The consumer provides `name`, an optional `tagline`, and its own `mark` as an SVG element built from rect, ellipse and polygon primitives. Without a `mark`, a neutral construction placeholder shows the grid; `markSize` sets its pixel size.

The tagline is uppercase; set `taglineCasing` to `asWritten` to keep it as written. The lockup reads as one image with the name and tagline as its label, so don't repeat them as text beside it.
