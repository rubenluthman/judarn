Card groups related content on `jd-surface-elevated`, separated from the page by fill contrast.

The consumer provides `eyebrow`, `title`, `children`, `media`, `actions`, `flat` and `compact`, and places the card on `jd-substrate`. Use `compact` in sidebars and dense panes. The eyebrow is uppercase; set `eyebrowCasing` to `asWritten` when it holds a unit, a digit or a mixed-case term.

Never add a border or stroke around a card. The eyebrow takes `--accent`, so it needs a color from the `text` tier.
