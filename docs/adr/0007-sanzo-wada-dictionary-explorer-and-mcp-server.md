# Sanzo Wada Dictionary, Explorer, and MCP Server
Status: Active · 2026-10-31

## Decision

Sanzo Wada's 348 colour combinations are an opt-in add-on, calibrated in OKLCh. They are not part of Judarn's core identity.

- The data lives in `tools/wada-explorer/data/`, and the `theme` key in `tokens/judarn-tokens.json` holds the harmony metadata. A zero-dependency local MCP server in `tools/wada-explorer/` (stdio JSON-RPC) lets agents search and evaluate palettes. `tools/wada-explorer/index.html` is generated by `scripts/build-wada-explorer.js`.
- A full harmony theme that replaces the substrate is never a default. Nothing applies one unless a project or its owner asks. No single combination is ever the default palette.
- Harmonies never appear in the invariants of `docs/DESIGN.md`, and none is labelled standard or default.
- Core contrast guarantees cover only Judarn's own surfaces. A harmony that fails the core matrix is not a defect, and the compile-time checks ([ADR-0005](0005-compile-time-contrast-checks-and-gamut-mapping.md)) must not treat it as one.
- Harmonies are not compiled into Swift or CSS without a new record.
- The `theme` key stays, with a `$description` stating its optional status, because consumers outside this repository may read it.

## Why

An agent once read the harmonies as the core palette and reported a failing harmony as a defect, because harmony #264's `ink60` reaches only about 2.4 to 3.3:1 on its light surfaces. That is expected for an optional palette and alarming for a core one. A local MCP server serves agents through a standard protocol with no hosted service or supply chain.

## What we gave up

- **Proven contrast on harmonies.** Whoever uses one verifies foreground contrast per use.
- **Automatic calibration.** Each new palette needs manual OKLCh work.
- **A clearer key name.** `theme` is misleading, but renaming it may break outside consumers.
- **A hosted service.** Agent clients must attach to the local server.

## Revisit if

The owner wants harmonies as a core theme, or no outside consumer reads the `theme` key any more.
